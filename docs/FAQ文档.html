📦 一、订单类 FAQ

如何查询我的订单状态？订单

标准回复： 您好！请提供您的订单号，我可以立即为您查询订单状态。您也可以在"我的订单"页面查看所有订单的实时状态。

常见问法：

  • "查一下我的订单"
  • "订单到哪一步了"
  • "我的订单处理得怎么样了"

系统流程： 触发 order_status_query → 收集 order_number 槽位 → 调用 GET /orders/{order_id}/status → 展示状态

订单有哪些状态？分别代表什么意思？订单

标准回复： 我们的订单状态包括以下几种：

  • 待发货 — 商家正在备货，预计 24 小时内发出。
  • 待揽收 — 商家已打包完成，正在等待物流揽收。
  • 运输中 — 包裹已发出，正在配送途中。
  • 已完成 — 订单已签收完成。
  • 已取消 — 订单已取消，款项将在 1-3 个工作日内原路退回。
如何取消订单？订单

标准回复： 订单取消规则如下：

  • 待发货状态：可以直接取消，取消后退款将原路返回。
  • 待揽收状态：可以联系客服尝试拦截，不保证成功。
  • 已发出（运输中）：无法取消订单，建议收到后申请退货退款。

注意： 订单取消后无法恢复，请谨慎操作。若包含赠品、优惠券等促销商品，关联促销也将一并取消。

订单金额不对 / 有优惠没有生效？订单

标准回复： 非常抱歉给您带来困扰！请您提供订单号，我来核实订单金额和优惠的使用情况。如果确实有优惠未生效，我会为您补登记录并跟进处理。

处理逻辑： 通过 GET /orders/{order_id} 获取订单金额明细，与用户确认后人工跟进。

能否催一下发货？订单

标准回复： 当然可以！我这就为您创建发货提醒，仓库会优先处理您的订单。一般来说，待发货订单会在 24 小时内发出。

系统流程： 对待发货/待揽收订单调用 POST /orders/{order_id}/shipping-reminders 创建催发货记录。

限制： 已发货（运输中/已完成）的订单不支持催发货。

🚚 二、物流类 FAQ

如何查询物流信息？物流

标准回复： 请告诉我您的订单号，我马上为您查询物流进度、快递公司和运单号。

常见问法：

  • "我的快递到哪了"
  • "包裹什么时候能到"
  • "物流信息怎么查"

系统流程： 触发 logistics_tracking → 收集 order_number → 调用 GET /orders/{order_id}/logistics → 展示物流轨迹

一般几天能收到货？物流

标准回复： 发货后一般 3-5 天可以收到货（偏远地区可能稍久）。江浙沪地区通常 24 小时内可达。具体到货时间受快递公司影响，我不做绝对承诺，但您的订单我会持续关注。

发的是哪家快递？能指定快递吗？物流

标准回复： 我们合作的快递公司包括京东物流、顺丰速运等。系统会根据收货地址自动选择最优快递。如需指定快递，请在下单时备注或联系客服，我们会尽量满足。

发货了但物流信息没更新怎么办？物流

标准回复： 非常理解您的心情！物流信息未更新可能是快递公司还未录入新信息，或同步有延迟，不会影响正常收货。我先帮您查询一下最新状态，如果确实异常，会立即联系快递公司核实。

能修改收货地址吗？物流

标准回复： 如果订单还未发货，您可以直接告诉我新地址，我帮您修改。如果已经发货了，暂时不支持修改地址，建议原地址有人代收，收到后帮您转寄。

能指定派送时间吗？物流

标准回复： 普通快递一般不支持指定派送时间。建议您留意物流信息，一旦显示快递员在派送，可以联系快递员协商一个合适的时间。

💰 三、退款售后类 FAQ

如何申请退款？退款

标准回复： 您好！请提供以下信息，我帮您提交退款申请：

  • 订单号
  • 退款原因（如：商品质量问题、不想要了、与描述不符等）

常见问法：

  • "我要退款"
  • "这个订单退钱"
  • "商品不想要了怎么退"

系统流程： 触发 refund_request → 收集 order_number + refund_reason → 调用 POST /orders/{order_id}/refund-applications

支持七天无理由退换货吗？退款

标准回复： 支持七天无理由退换货（贴身衣物、定制类除外，以商品页标注为准）。商品需不影响二次销售，赠品需一并退回。您可以在订单页面点击"申请售后"按提示操作。

退款多久能到账？退款

标准回复： 退款申请提交后，我们会在 1-3 个工作日内审核处理。审核通过后，退款将原路返回您的支付账户。到账时间取决于支付渠道，一般 1-5 个工作日。

退货运费由谁承担？退款

标准回复： 运费承担规则如下：

  • 质量问题：来回运费由商家承担。
  • 非质量问题（七天无理由）：顾客承担寄回运费，商家承担寄出运费。

本店商品默认赠送运费险，退货成功后保费理赔自动到账，无需单独申请。

收到商品破损 / 发错货了怎么办？退款

标准回复： 非常抱歉给您带来不好的体验！请您拍照发给我核实一下，确认后我们立即为您补发正确商品或办理退款，来回运费由我们承担。

退款申请提交后能撤销吗？退款

标准回复： 如果退款申请还在审核中，您可以联系客服撤销。如果已经审核通过并退款，则无法撤销，需要重新下单购买。

系统限制： 同一订单如果已有进行中（submitted/processing）的退款申请，不允许重复提交。

🛍️ 四、商品咨询类 FAQ

如何查询商品详情？商品

标准回复： 您可以点击商品卡片查看详情，或告诉我商品名称/编号，我帮您查询商品的价格、库存和规格信息。

系统流程： 用户点击商品卡片发送 object 消息 → 系统调用 GET /products/{product_id} → 返回商品详情

商品有现货吗？商品

标准回复： 商品页面显示"有货"的都是现货，可以直接拍下付款。如果显示缺货，建议先加入购物车，到货后我们会通知您。

有类似的商品推荐吗？商品

标准回复： 当然！请先选择一个您感兴趣的商品，我会为您推荐类似的商品。

系统流程： 触发 similar_product_recommendation → 检查 product_id 槽位 → 如缺失则追问 → 调用推荐接口

商品价格是多少？商品

标准回复： 请告诉我您想了解的商品名称或编号，我马上为您查询最新价格。您也可以直接点击商品卡片查看。

可以开发票吗？商品

标准回复： 可以的！下单时在"发票信息"处填写好抬头和税号，我们会随货一起寄出电子发票。如需增值税专票，请联系客服按专票流程开具。

💬 五、通用类 FAQ

你们能帮我处理哪些问题？通用

标准回复： 您好！这里是 itwwy 电商助手。我可以帮您：

  • 查询订单状态
  • 查询物流信息
  • 了解商品详情
  • 提交退款申请
  • 推荐相似商品
  • 转接人工客服
如何联系人工客服？通用

标准回复： 您可以直接说"转人工客服"或"人工服务"，系统会立即为您转接人工客服，请稍等。

系统流程： 触发 human_handoff flow → 回复"转接人工客服"

有优惠活动吗？怎么领优惠券？通用

标准回复： 您可以点进商品页面，在价格下方有"领券"按钮，点击即可领取可用优惠券。大促期间还有满减活动，具体以活动页面为准。

你们的服务时间是？通用

标准回复： 智能客服 7×24 小时在线，随时为您服务。人工客服工作时间为每天 9:00-22:00，非工作时间请留言，我们会在工作时间第一时间回复您。

我的会员等级有什么用？通用

标准回复： PLUS 会员可享受专属客服优先通道、免费退换货、专属优惠券等权益。普通会员也可享受七天无理由退换货和基础客服服务。

商品有问题怎么投诉？通用

标准回复： 非常抱歉给您带来不好的体验！您的心情我完全理解，这件事我第一时间升级给主管，主管会在 30 分钟内亲自与您联系。为便于快速核实，方便告知订单号吗？

怎么修改收货人信息？通用

标准回复： 如果订单还未发货，您可以直接告诉我新的收货人姓名、电话和地址，我帮您修改。如果已发货，需要联系快递公司修改派送信息。

支持哪些支付方式？通用

标准回复： 我们支持微信支付、支付宝、银行卡等多种支付方式。下单后选择您方便的支付方式即可。退款会原路返回您的支付账户。

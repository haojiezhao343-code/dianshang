发现并修复的 Bug

Bug #1：客服后端 http_client 未初始化（已修复）

文件： customer-service-backend/api/app.py

现象： 所有涉及电商后端 API 调用的对话（查订单状态、查物流）都返回"查询失败"，因为 http_client 全局变量始终为 None。

根因： lifespan 函数中只调用了 init_db_engine()，遗漏了 init_http_client()，导致 http_client 从未被初始化。

修复： 在 lifespan 中添加 init_http_client()（启动时）和 await close_http_client()（关闭时）。

影响范围： lookup_order_status、lookup_logistics 等所有调用电商后端 API 的 action。

修复验证： 修复后重新测试 CHAT-02（订单状态多轮查询），成功返回"包裹已发出，正在配送途中。订单金额 ¥149.00"。

三、客服对话引擎测试（12 条）

测试方式： 通过 POST http://127.0.0.1:18082/api/chat 发送对话消息，验证意图识别、槽位收集、多轮对话、意图切换等能力。
注意： 对话引擎依赖 LLM（硅基流动 DeepSeek-V4-Flash），沙箱出网受限时可能返回兜底话术。
CHAT-01对话 欢迎引导（onboarding）
输入： "你好"
预期： 触发 onboarding flow，回复中提及"查订单、查物流、商品信息、退款"
命令： 
curl -s -X POST http://127.0.0.1:18082/api/chat \
  -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat01","text":"你好"}'
CHAT-02对话 订单状态查询 — 完整多轮对话
第 1 轮输入： "我想查一下订单状态"
预期 1： 识别意图=order_status_query，追问"请告诉我你的订单号"
第 2 轮输入： "A20260410001"
预期 2： 回复包含订单状态"待发货"
命令： 
# 第 1 轮
curl -s -X POST http://127.0.0.1:18082/api/chat \
  -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat02","text":"我想查一下订单状态"}'

# 第 2 轮（同一 sender_id 维持上下文）
curl -s -X POST http://127.0.0.1:18082/api/chat \
  -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat02","text":"A20260410001"}'
CHAT-03对话 订单状态查询 — 一次性给出订单号
输入： "帮我查一下订单A20260408002的状态"
预期： 单轮完成，回复包含"运输中"
命令： 
curl -s -X POST http://127.0.0.1:18082/api/chat \
  -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat03","text":"帮我查一下订单A20260408002的状态"}'
CHAT-04对话 物流查询 — 多轮对话
第 1 轮输入： "我的快递到哪了"
预期 1： 识别意图=logistics_tracking，追问订单号
第 2 轮输入： "A20260408002"
预期 2： 回复包含"京东物流"和运单号 JD000123456789
命令： 
curl -s -X POST http://127.0.0.1:18082/api/chat \
  -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat04","text":"我的快递到哪了"}'
curl -s -X POST http://127.0.0.1:18082/api/chat \
  -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat04","text":"A20260408002"}'
CHAT-05对话 退款申请 — 多轮对话（收集订单号 + 退款原因）
第 1 轮： "我要申请退款" → 追问订单号
第 2 轮： "A20260407004" → 追问退款原因
第 3 轮： "商品与描述不符" → 确认退款申请已提交
命令： 
curl -s -X POST http://127.0.0.1:18082/api/chat -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat05","text":"我要申请退款"}'
curl -s -X POST http://127.0.0.1:18082/api/chat -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat05","text":"A20260407004"}'
curl -s -X POST http://127.0.0.1:18082/api/chat -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat05","text":"商品与描述不符"}'
CHAT-06对话 人工客服转接
输入： "转人工客服"
预期： 触发 human_handoff flow，回复"转接人工客服"
命令： 
curl -s -X POST http://127.0.0.1:18082/api/chat -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat06","text":"转人工客服"}'
CHAT-07对话 对象消息 — 点击订单卡片查询
输入： object 消息，{"type":"order","id":"A20260407004"}
预期： 返回该订单的相关信息（状态或详情）
命令： 
curl -s -X POST http://127.0.0.1:18082/api/chat -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat07","object":{"type":"order","id":"A20260407004","title":"Apple Watch"}}'
CHAT-08对话 意图切换 — 查订单中途改查物流
第 1 轮： "查订单状态" → 追问订单号
第 2 轮： "算了，我想查物流" → 识别意图切换，追问订单号（logistics_tracking）
命令：

  -d '{"sender_id":"test_chat08","text":"查订单状态"}'
curl -s -X POST http://127.0.0.1:18082/api/chat -H "Content-Type: application/json" \
  -d '{"sender_id":"test_chat08","text":"算了，我想查物流"}'
CHAT-09对话 相似商品推荐
输入： "有没有类似的商品推荐"
预期： 触发 similar_product_recommendation flow，可能追问商品 ID
命令： 
curl -s -X POST http://127.0.0.1:18082/api/chat -H "Content-Type: application/json" \

curl -s -X POST http://127.0.0.1:18082/api/chat -H "Content-Type: application/json" \
